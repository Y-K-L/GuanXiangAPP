# 观象 · 周易卦象学习小程序

一个把《周易》的符号结构做成可玩交互的微信小程序。不占卜、不算命，定位为传统文化与符号学习工具。

## 功能

- **爻线工坊**：点击爻线，阴阳互变，实时查看卦名与象意。
- **卦象拼图**：识别八卦、按卦名拼上下卦，答对解锁图鉴。
- **每日一卦**：按日期推送情境题，判断哪一卦更贴合处境。
- **卦象图鉴**：收集已解锁的六十四卦。

## 本地运行

1. 安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开工具 → 新建项目 → 导入本目录。
3. AppID 可先用 `touristappid`（测试号），正式发布前替换为自己的 AppID。
4. 点击"编译"即可在模拟器运行，点"预览"可用手机扫码。

## 目录结构

- `core/`：纯逻辑模块（八卦编码、六十四卦查找、爻关系），不依赖小程序 API。
- `data/`：六十四卦基础数据、拼图关卡、每日一卦题库。
- `pages/`：5 个页面（学习首页、工坊、拼图、每日、图鉴）。

## 扩展方向

- 用云开发（云数据库 + 云函数）替换本地 Storage，实现多端进度同步。
- 增加爻位迷宫模块（`core/relations.js` 已提供"比、应、中、正"判定）。
- 补充完整卦辞、爻辞与白话解读。

## 声明

本项目仅用于《周易》符号结构与义理的学习，不提供占卜、预测吉凶等功能，避免任何迷信导向的使用。
